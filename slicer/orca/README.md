# Orca presets

Import in Snapmaker Orca 2.3.5: copy each JSON into the matching folder of your Orca user profile
(`~/.config/Snapmaker_Orca/user/default/{machine,process,filament}/` on Linux) and restart Orca,
or use File → Import → Import Configs. Set the printer address in the machine preset yourself
(it is blanked here). See [presets.md](presets.md) for the system preset each one inherits from.
